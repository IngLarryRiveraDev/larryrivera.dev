# larryrivera.dev

Portafolio personal de **Larry Rivera**, desarrollador web full-stack de Costa Rica.

🔗 **En vivo:** [larryrivera.dev](https://larryrivera.dev)

## Qué tiene

- Página de una sola vista, bilingüe (español / inglés) con un botón para cambiar de idioma.
- Proyectos reales: [Pizza Yaja](https://pizzeriayaja.com) (sitio web + sistema POS) y [Abstract Concrete & Flooring](https://abstractflooringsolutions.com).
- CV descargable.
- Se adapta a celular y respeta la opción de "reducir movimiento" del sistema.

## Cómo está hecho

HTML, CSS y JavaScript puros, en un solo archivo (`index.html`), sin frameworks ni librerías. Solo usa Google Fonts.
Publicado en Hostinger.

## Verlo en tu compu

Abrí `index.html` en el navegador, o levantá un servidor local:

```bash
npx serve .
```
